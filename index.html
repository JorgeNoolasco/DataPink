O DESAFIO: DA CONFUSÃO À INTEGRIDADE RELACIONAL

Dados conectados,
informação com contexto.

Uma planilha isolada pode duplicar registros e esconder relações. Um banco relacional organiza entidades e mantém seus vínculos consistentes.

▦01 / ORGANIZAÇÃO

Desorganização de arquivos

Dados espalhados dificultam buscas, atualizações e a leitura do histórico acadêmico.

⌘02 / REDUNDÂNCIA

Redundância de dados

Repetir os mesmos dados aumenta erros e inconsistências.

↗03 / MODELAGEM

Dificuldade de consulta

Relações explícitas ajudam a responder perguntas com filtros e junções claras.

✓04 / INTEGRIDADE

Integridade referencial

Chaves estrangeiras impedem vínculos para registros inexistentes.

CONSULTA DE EXEMPLOPostgreSQL
SELECT a.nome_aluno, c.nome_curso, n.valor_nota
FROM public.aluno AS a
JOIN public.matricula AS m ON m.id_aluno = a.id_aluno
JOIN public.turma AS t ON t.id_turma = m.id_turma
JOIN public.curso AS c ON c.id_curso = t.id_curso
LEFT JOIN public.nota AS n ON n.id_matricula = m.id_matricula
ORDER BY a.nome_aluno;

Uma consulta relaciona tabelas pelos identificadores e retorna apenas os campos necessários.
